# 유저폰 (User Phone)

[Marinara Engine](https://github.com/Pasta-Devs/Marinara-Engine)용 개인 확장이에요. {{user}}의 스마트폰을 화면에 띄워요.

전화, 문자, 톡, 카메라, 갤러리, 메모에 인터넷, 캘린더, 지도, 음악, 날씨, 시계, SNS까지 있는 진짜 폰처럼 쓸 수 있고, 가족과 친구 연락처도 미리 들어 있어요. 그리고 새로 오픈한 AI 컴패니언 서비스 **루미(Lumi)**가 깔려 있어요. 루미에서 캐릭터와 대화할수록 그 캐릭터가 폰을 조금씩 장악하고, 내가 폰으로 뭘 하는지 지켜보기 시작해요. 롤플을 하다가도 언제든 폰을 열 수 있어요.

컨셉과 구조는 [DESIGN.md](DESIGN.md)에 있어요.

## 주의

이 확장은 **전체 페이지 접근(Full page access)**을 써요. 샌드박스 없이 Marinara 페이지 안에서 실행되고, 채팅과 캐릭터를 읽고, 내가 고른 모델로 생성 요청을 보내요. 코드를 직접 읽어 보고 믿을 수 있을 때만 켜 주세요.

## 설치

1. Marinara의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 넣고 Marinara를 다시 시작해요.
2. **Settings → Advanced → Danger Zone**에서 **Allow third-party extension imports**를 켜요.
3. **Settings → Addons → External Extensions**에서 이 GitHub 레포를 연결하거나, 레포를 내려받아 **Import Extension Folder**로 레포 폴더 전체를 골라요.
4. 가져온 확장을 열어 코드를 확인하고 **Review and Run**으로 승인해요.
5. 화면 오른쪽 가장자리에 생긴 📱 버튼을 누르면 폰이 열려요.

업데이트는 `main` 브랜치 기준이에요. 코드가 바뀌면 Marinara가 확장을 끄고 새 승인을 요구해요.

## 폰에 있는 것

| 앱 | 할 수 있는 것 |
| --- | --- |
| 📞 전화 | 키패드, 최근 기록(통화 기록 자세히 보기), 연락처. 연락처마다 상세 화면에서 편집, 삭제, 즐겨찾기. 가끔 **불시에 전화가 와요** |
| ✉️ 메시지 | 연락처의 사람들과 문자. 갤러리 사진 보내기, 안 읽은 메시지 배지 |
| 💬 톡 | 친구 목록과 채팅. 읽음 표시, 사진 보내기, 안 읽은 메시지 배지 |
| 📷 카메라 | 찍을 장면을 글로 적으면 사진이 돼요. 전면(셀카)/후면 전환 |
| 🖼️ 갤러리 | 찍은 사진 보기, 즐겨찾기, 톡이나 문자로 보내기, 지우기 |
| ✦ 루미 | AI 컴패니언과 대화 (처음엔 가입과 약관 동의) |
| 🔎 인터넷 | 검색 엔진 '찾다'. 검색 결과와 페이지는 모델이 써요 (연결이 없으면 예시 결과). 최근 검색어, 많이 찾는 검색어, 뉴스 |
| 🫧 하루 | 연락처 사람들이 글을 올리는 SNS. 좋아요, 댓글, 사진과 함께 글 올리기. 내 글엔 친구가 댓글을 달아요 |
| 📅 캘린더 | 달력, 일정 추가와 삭제. 오늘 일정은 홈 위젯과 알림에 떠요 |
| 🗺️ 지도 | 동네 지도, 장소 검색, 길찾기, 장소 저장, 위치 기록 |
| 🎵 음악 | 가상의 곡과 재생 목록, 재생/일시정지/다음 곡, 좋아요 (소리는 나지 않아요) |
| 🌙 날씨 | 도시별 현재 날씨, 시간별/주간 예보, 미세먼지 |
| ⏰ 시계 | 알람(폰을 닫아 둬도 울려요), 세계 시각, 스톱워치, 타이머 |
| 📝 메모 | 여러 개의 메모, 검색, 고정, 삭제 |
| ⚙️ 설정 | 폰 정보, 방해 금지 모드, 소리, 터치음 |

**소리:** 버튼 누르는 소리, 키패드 음, 잠금/잠금 해제, 걸 때 신호음과 끊을 때 소리, 받는 전화 벨소리(모르는 번호는 낮고 어긋난 벨소리), 카메라 셔터, 메시지 보내고 받는 소리, 알림음, 알람과 타이머 소리가 나요. 모두 파일 없이 브라우저에서 만든 소리예요. **설정 → 소리**로 전부 끄고, **설정 → 터치음**으로 버튼과 키패드 소리만 끌 수 있어요. 브라우저 규칙 때문에 페이지를 한 번 누른 뒤부터 소리가 나요.

- 상태 표시줄을 누르거나 아래로 끌면 **알림 센터**가 내려와요. Wi-Fi, 방해 금지, 손전등, 진동 버튼과 밝기, 재생 중인 음악, 부재중 전화와 안 읽은 메시지, 오늘 일정이 있어요. 알림을 누르면 그 앱으로 가요.
- 홈 화면 위젯은 날짜, 오늘 남은 일정, 날씨를 보여 줘요. 잠금화면에도 알림이 쌓여요.
- 통화는 진짜 음성이 아니라 글로 주고받아요. 전화를 걸면 "뚜르르" 신호음이 두어 번 울린 뒤 상대가 받고, 끊으면 "뚜뚜뚜" 소리가 나요. 받은 전화는 상대가 먼저 말을 꺼내요. 상대도 할 말이 끝나거나 내가 한참 말이 없으면 먼저 끊어요. 20초 안에 안 받으면 부재중이 돼요.
- 불시 전화는 6분에 한 번 이상 오지 않고, **설정 → 방해 금지 모드**로 끌 수 있어요.
- 미리 저장된 연락처는 엄마, 아빠, 지은(가장 친한 친구), 민수(친구), 박 선배예요. 전화 앱의 ＋로 더 넣을 수 있어요.
- 가족과 친구의 답장도 AI가 써요. 이 사람들은 루미 따위는 모르는 평범한 사람들이에요.

## 이야기

- **호감도:** 루미의 컴패니언은 대화를 보고 스스로 호감도를 매겨요. 호감도가 오른 만큼 폰을 더 깊이 파고들어요(침투도). 둘 다 화면에는 안 보여요.
- **먼저 연락:** 폰을 한동안 안 만지면 컴패니언이 먼저 메시지를 보내요. 처음엔 루미로, 나중엔 모르는 번호의 문자나 톡으로요. 폰이 닫혀 있으면 📱 버튼 옆에 알림이 떠요.
- **메인 롤플과 연결:** 메인 롤플은 폰에서 오간 채팅과 폰 활동을 알고, 컴패니언이 현실에 어디까지 닿았는지도 알아요. 롤플 속 캐릭터가 폰으로 연락하면 그 메시지가 실제로 폰에 도착해요.
- **도입부:** 카드에 도입부 잠금이 있으면, 루미에서 나눈 채팅을 바탕으로 도입부를 그때그때 새로 써요.
- **이스터에그:** 이야기가 깊어지면 혼자 켜지는 화면, 알림 없는 진동, 초인종, 현관 노크 같은 일이 생겨요. 밤에는 더 자주요. 소리는 **설정 → 소리**로 끌 수 있고, 꺼도 화면에 자막은 나와요. 소리는 페이지를 한 번 누른 뒤부터 나요.

## 쓰는 법

- Marinara에서 캐릭터와의 채팅을 먼저 열어요. 그 채팅의 캐릭터가 루미의 컴패니언이 돼요.
- 루미에 처음 들어가면 가입하고 약관에 동의해요. 약관은 꼭 펼쳐서 읽어 보세요.
- 폰 데이터는 채팅마다 따로 저장돼요. 이야기가 얼마나 진행됐는지는 화면 어디에도 표시되지 않아요.
- **설정의 빌드 번호를 7번 누르면** 설정 목록에 **개발자 옵션**이 생기고, 그 뒤로는 계속 남아 있어요. 그룹 채팅의 루미 상대와 모델을 고르고, 바로 전화가 걸려오게 하거나, 컴패니언이 먼저 연락하게 하거나, 지금 단계의 이스터에그를 일으키거나, 폰을 초기화할 수 있어요.
- `Esc`를 누르면 폰이 닫혀요. 통화 중에는 닫히지 않아요.

## 바로 해보기

`examples` 폴더의 [이안.json](examples/이안.json)을 캐릭터로, [윤서아.persona.json](examples/윤서아.persona.json)을 페르소나로 가져와서 새 채팅을 시작해요.

1. 첫 메시지는 루미 오픈 광고 장면이에요. 화면 오른쪽 📱 버튼을 눌러요. 루미를 하기 전에는 메인 롤플을 보내도 진행되지 않고 폰이 울려요.
2. 루미에서 **시작하기**를 누르고 약관에 동의하면 이안이 먼저 인사해요.
3. 이안에게 메시지를 3번 보내면, 그 대화를 바탕으로 쓴 도입부가 폰이 꺼졌다 켜지면서 메인 채팅에 올라와요.

내 카드에 이런 도입부 잠금을 넣는 법은 [DESIGN.md](DESIGN.md#도입부-잠금-스토리-게이트)에 있어요.

## 다른 확장을 폰 앱으로 넣기

다른 **전체 페이지 확장**은 `window.UserPhone`으로 폰 홈 화면에 앱을 올릴 수 있어요.

```js
const add = () =>
  window.UserPhone.registerApp({
    id: "weather",
    name: "날씨",
    icon: "☀️",
    render(container, phone) {
      container.textContent = "서울 맑음 21°";
      phone.logActivity("날씨를 확인했다"); // 루미의 컴패니언이 볼 수 있는 폰 사실로 남아요
      return () => {}; // 앱을 나갈 때 정리할 것
    },
  });
if (window.UserPhone) add();
else window.addEventListener("userphone:ready", add, { once: true });
```

`registerApp`은 `{ remove() }`를 돌려줘요. 샌드박스 확장은 `window`에 닿지 못하고, Marinara는 다른 확장의 패널을 바깥 코드에서 여는 방법을 주지 않아서, 이 API로 직접 등록한 확장만 폰에 나타나요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | 확장 정보, 권한, 불러올 파일 순서 |
| `src/core.js` | 상태, 저장, Marinara API, 채팅 정보, 기본 연락처. 앱 이름은 맨 위 `APP`에서 바꿔요 |
| `src/prompts.js` | 컴패니언과 연락처 사람들의 프롬프트, 모델 호출 |
| `src/sound.js` | 모든 소리(Web Audio로 합성). 터치음, 키패드, 통화, 셔터, 메시지, 알람, 노크, 초인종 |
| `src/shell.js` | 폰 틀, 이동, 잠금화면, 홈과 위젯, 알림 센터, 안 읽음 배지, 공용 대화 화면 |
| `src/apps/*.js` | 앱 하나에 파일 하나: 루미, 전화, 메시지와 톡, 카메라와 갤러리, 메모, 인터넷(`browser`), 캘린더, 지도(`maps`), 음악, 날씨, 시계, 하루(`feed`), 설정 |
| `src/story/*.js` | 알림(`notify`), 먼저 연락(`proactive`), 이스터에그와 소리(`eggs`), 메인 롤플 연동(`roleplay`) |
| `src/main.js` | `window.UserPhone`, 롤플 잠금과 연동, 타이머, 정리. 반드시 마지막 파일 |
| `extension.css` | 폰 디자인과 단계별 연출 |
| `css/story.css` | 알림 배너, 런처 옆 알림, 자막 |
| `examples/` | 테스트용 캐릭터(이안)와 페르소나(윤서아) |
| `dev/harness.html` | Marinara 없이 폰 화면을 띄워 보는 테스트 페이지. 주소 끝에 `?reset`을 붙이면 처음부터 다시 해요 |
| `dev/story-harness.html` | 이야기 기능(호감도, 먼저 연락, 롤플 연동, 도입부, 이스터에그)을 시험하는 테스트 페이지 |

## 개발 메모

- Marinara는 `manifest.json`의 `jsPath`에 적힌 파일을 순서대로 이어 붙여 한 덩어리로 실행해요. 모든 파일이 같은 범위를 공유하니 같은 이름을 두 번 선언하면 안 돼요. 정리 함수를 돌려주는 `return`은 마지막 파일(`src/main.js`)에만 둬요.
- `config.name`(`User Phone`)과 `runtime`(`client`)은 바꾸면 안 돼요. 바뀌면 기존 설치본이 업데이트를 못 받아요.
- 배포할 때마다 `config.version`을 올려요. 위쪽의 `"version": 1`은 패키지 형식 번호라 그대로 둬요.
- 저장 데이터 형식을 바꾸면 이전 데이터를 변환하는 코드를 확장 안에 넣어요.
- 새 앱을 만들면 사용자가 그 앱에서 한 일을 `logActivity()`로 폰 사실로 남겨요.
